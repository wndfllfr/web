
# Image Processing Web Application

Лабораторная работа по разработке веб-сервисов.

## Возможности

- Загрузка изображений PNG и JPG.
- Проверка формата и размера изображения.
- Рисование вертикальной или горизонтальной линии.
- Выбор цвета и толщины линии.
- Построение RGB-гистограмм.
- Проверка пользователя с помощью CAPTCHA.

## Установка

pip install -r requirements.txt

## Запуск

python app.py

## Тестирование

pytest -v
